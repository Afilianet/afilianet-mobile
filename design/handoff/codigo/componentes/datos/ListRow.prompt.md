Fila de cualquier lista del producto: red, pagos, ventas.

```jsx
<ListRow medio={<Avatar nombre="Luis Cárdenas" />} titulo="Luis Cárdenas" subtitulo="Nivel 1 · se unió el 14 ago" valor="$1,240" valorSecundario="MXN" />
```

Alto mínimo 64px. Las cifras siempre en mono para que las columnas se alineen.
